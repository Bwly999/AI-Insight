# 引用标注规范

报告里每条结论都必须能追溯到具体来源。用 `[n]` 标记引用，系统自动渲染为可交互的来源链接。

## 语法

- **单来源**：`[1]` — 引用第 1 条信号
- **多来源**：`[1,4,5]` — 同一结论由第 1、4、5 条信号支撑，逗号分隔
- **编号来源**：n 是工具结果里每条信号前的序号（①②③…跨整个对话累加，不会重复）

## 示例

```markdown
DeepSeek-V3 在 MMLU 上得分 88.5%[1]，超过 GPT-4o 的 87.2%[2,3]。
该模型在代码任务上表现突出[4,5,6]，但多模态能力尚未公开评测[7]。
```

## 规则

1. **编号必须真实**：n 只能是工具结果里实际出现的序号。不要编造、跳号或臆造不存在的来源。
2. **读过的原文 vs 摘要**：你不需要区分——系统自动判定。如果你对某信号调用了 `extract_content` 深读原文，该来源会渲染为可点击跳转的数字①；如果只用了搜索摘要，会渲染为可展开摘要的 🔗 标记。你只管写编号。
3. **无来源标「推测」**：无法追溯到工具返回信号的判断，显式标「推测」，不加 `[n]`。
4. **编号跨对话累加**：同一对话多次运行时，编号是全局连续的（第一次运行的信号是 1-N，第二次从 N+1 起）。工具结果里的序号已反映此全局编号，直接引用即可。
