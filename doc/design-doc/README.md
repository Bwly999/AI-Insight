## 文档约定

- 所有接口契约定义在 `packages/shared-types`，前后端共享，文档中的 TS 片段以该包为准。
- 文档中的「留白」标记表示该部分需由使用方在内网自行实现，平台仅提供接口与默认实现。
- 数据模型以 Drizzle `mysql-core` 表达，参见 [06-数据模型](./06-数据模型.md)。
