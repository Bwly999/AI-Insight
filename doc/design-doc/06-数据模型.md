# 06 · 数据模型

数据库：**MySQL**，ORM：**Drizzle (`drizzle-orm/mysql-core`)**，schema 与迁移由 `drizzle-kit` 管理。

> 下表为逻辑模型 + Drizzle 字段说明。实际 `.ts` schema 文件在 `apps/server/src/db/schema.ts`。

## 6.1 表清单

| 表 | 用途 |
|---|---|
| `users` | 用户（externalId 来自 JWT；role 后端库管理） |
| `categories` | 领域（管理端定义，对应原型 ai/bio/quant/...） |
| `sources` | 数据源（采集层概念，用户不直接订阅） |
| `collect_logs` | 采集运行日志 |
| `raw_items` | 采集原始项 |
| `articles` | AI 处理产物（全局共享池） |
| `report_schedules` | 报告调度目标（管理端定义，各自 cron） |
| `subscriptions` | 用户订阅（挂载到 schedule） |
| `reports` | 报告实体（每用户每期一条，按期存档） |
| `report_items` | 报告与 article 的关联 |
| `notification_logs` | 推送日志 |
| `feedback` | 用户反馈/收藏 |

## 6.2 详细 Schema

### users
```ts
{
  id:            serial('id').primaryKey(),
  externalId:    varchar('external_id', { length: 128 }).notNull().unique(),  // JWT.id
  name:          varchar('name', { length: 128 }).notNull(),
  role:          mysqlEnum('role', ['USER', 'ADMIN']).notNull().default('USER'),
  createdAt:     timestamp('created_at').default(now()),
  lastSeenAt:    timestamp('last_seen_at'),
}
```
- `externalId` 来自 JWT 的 `id`，唯一。
- `role` 由后端库管理，管理员可在管理端改（USER↔ADMIN）。
- 映射策略待定（建议首次见到 externalId 时自动建 USER 记录），见 [14-留白](./14-留白与后续确认.md)。

### categories
```ts
{
  id:        serial('id').primaryKey(),
  code:      varchar('code', { length: 64 }).notNull().unique(),   // 如 'ai','bio','quant'
  label:     varchar('label', { length: 128 }).notNull(),          // 显示名
  color:     varchar('color', { length: 16 }).notNull(),           // 如 '#c8341a'
  sortOrder: int('sort_order').default(0),
  enabled:   boolean('enabled').default(true),
}
```
- 领域由管理端定义，对应原型 5 个领域。用户订阅时勾选。

### sources
```ts
{
  id:        serial('id').primaryKey(),
  code:      varchar('code', { length: 64 }).notNull().unique(),
  name:      varchar('name', { length: 128 }).notNull(),
  type:      varchar('type', { length: 32 }).notNull(),   // 决定用哪个 ICollector
  config:    json('config').$type<Record<string, unknown>>(),  // 该源特有参数
  enabled:   boolean('enabled').default(true),
  createdAt: timestamp('created_at').default(now()),
}
```
- `type` ∈ `RSS` / `SEARCH_API` / `SEARCH_CRAWL` / `WEB_SCRAPER` / 自定义。
- `config` 承载 feed url / endpoint / 选择器 / api key 等；**敏感 key 加密存储**。

### collect_logs
```ts
{
  id:            serial('id').primaryKey(),
  sourceId:      int('source_id').notNull().references(() => sources.id),
  status:        mysqlEnum('status', ['RUNNING','SUCCESS','FAILED']).notNull(),
  startedAt:     timestamp('started_at').notNull(),
  finishedAt:    timestamp('finished_at'),
  itemsFetched:  int('items_fetched').default(0),
  itemsNew:      int('items_new').default(0),
  error:         text('error'),
}
```

### raw_items
```ts
{
  id:          serial('id').primaryKey(),
  sourceId:    int('source_id').notNull().references(() => sources.id),
  fingerprint: varchar('fingerprint', { length: 64 }).notNull().unique(),  // URL归一化+标题hash
  url:         text('url').notNull(),
  title:       varchar('title', { length: 512 }).notNull(),
  rawText:     text('raw_text'),
  publishedAt: timestamp('published_at'),
  capturedAt:  timestamp('captured_at').notNull().default(now()),
  dedupeKey:   varchar('dedupe_key', { length: 64 }),
}
```
- `fingerprint` 唯一约束 → 采集入库时跨源去重第一道。

### articles（AI 处理产物，全局共享池）
```ts
{
  id:           serial('id').primaryKey(),
  rawItemId:    int('raw_item_id').references(() => rawItems.id),
  categoryCode: varchar('category_code', { length: 64 }).references(() => categories.code),
  summary:      text('summary').notNull(),          // 中文摘要
  heat:         int('heat').notNull(),              // 0-100
  tags:         json('tags').$type<string[]>(),
  critical:     boolean('critical').default(false), // 头条推荐
  trendComment: text('trend_comment'),              // 综合点评（深度报告）
  processedAt:  timestamp('processed_at').notNull().default(now()),
}
```

### report_schedules（报告调度目标）
```ts
{
  id:          serial('id').primaryKey(),
  name:        varchar('name', { length: 128 }).notNull(),   // 如 "每日早报"/"每周周报"
  cron:        varchar('cron', { length: 64 }).notNull(),     // 该目标 cron
  periodHours: int('period_hours').notNull(),                 // 覆盖时间窗（裁剪范围）
  enabled:     boolean('enabled').default(true),
  createdAt:   timestamp('created_at').default(now()),
}
```
- 每个 schedule 独立 cron，触发时为该 schedule 下所有 active subscription 裁剪组装 Report。

### subscriptions
```ts
{
  id:            serial('id').primaryKey(),
  userId:        int('user_id').notNull().references(() => users.id),
  scheduleId:    int('schedule_id').notNull().references(() => reportSchedules.id),
  categoryCodes: json('category_codes').$type<string[]>(),     // 领域
  keywords:      json('keywords').$type<string[]>(),           // 关键词
  channels:      json('channels').$type<string[]>(),           // 推送通道偏好，如 ['EMAIL','WECOM']
  active:        boolean('active').default(true),
  updatedAt:     timestamp('updated_at').default(now()),
}
```
- 订阅 = 领域 + 关键词 + 挂载的 schedule + 通道偏好。
- 裁剪命中规则：`categoryCodes ∪ keywords` 命中 Article。

### reports（报告实体）
```ts
{
  id:           serial('id').primaryKey(),
  issueNo:      varchar('issue_no', { length: 32 }).notNull(),
  userId:       int('user_id').notNull().references(() => users.id),
  scheduleId:   int('schedule_id').notNull().references(() => reportSchedules.id),
  periodStart:  timestamp('period_start').notNull(),
  periodEnd:    timestamp('period_end').notNull(),
  headlineJson: json('headline_json').$type<unknown>(),        // 该用户头条
  bodyJson:     json('body_json').$type<unknown>(),            // 组装条目+个性化点评
  status:       mysqlEnum('status', ['GENERATING','READY','SENT','FAILED']).notNull(),
  createdAt:    timestamp('created_at').default(now()),
  sentAt:       timestamp('sent_at'),
}
```
- 每用户每期一条，实体化存档，用户端「打开即读」。

### report_items
```ts
{
  reportId:  int('report_id').notNull().references(() => reports.id),
  articleId: int('article_id').notNull().references(() => articles.id),
  sortOrder: int('sort_order').notNull(),
  section:   varchar('section', { length: 32 }),   // 如 'headline' / 'featured' / 'archive'
}
```

### notification_logs
```ts
{
  id:        serial('id').primaryKey(),
  userId:    int('user_id').notNull().references(() => users.id),
  reportId:  int('report_id').references(() => reports.id),
  channel:   varchar('channel', { length: 32 }).notNull(),   // 'CONSOLE' / 'EMAIL' / ...
  status:    mysqlEnum('status', ['PENDING','SUCCESS','FAILED']).notNull(),
  payload:   json('payload').$type<NotificationPayload>(),
  error:     text('error'),
  createdAt: timestamp('created_at').default(now()),
}
```
- 管理端可见、可手动重推。

### feedback
```ts
{
  id:        serial('id').primaryKey(),
  userId:    int('user_id').notNull().references(() => users.id),
  articleId: int('article_id').notNull().references(() => articles.id),
  type:      mysqlEnum('type', ['USEFUL','USELESS','COLLECT']).notNull(),
  note:      text('note'),
  createdAt: timestamp('created_at').default(now()),
}
```
- 反馈数据回流可优化推荐（v2）。

## 6.3 去重策略（无 embedding）

因内网 LLM 无 embedding：

1. **第一道（采集入库）**：`fingerprint = hash(URL归一化 + 标题)`，`raw_items.fingerprint` 唯一约束，重复采集不产生新记录。
2. **第二道（AI 处理）**：processing 阶段把可疑相似条目（标题/摘要相近）打包交给 LLM 判同，标记丢弃。

**无需 pgvector / 向量索引**，纯 MySQL + LLM 判断即可。

## 6.4 迁移管理

- schema 文件：`apps/server/src/db/schema.ts`。
- 迁移目录：`apps/server/drizzle/`。
- 命令：`pnpm db:gen`（生成迁移）→ `pnpm db:push`（应用迁移）。
- 由 `drizzle-kit` 管理，纳入版本控制。
