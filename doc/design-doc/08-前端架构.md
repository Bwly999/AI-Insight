# 08 · 前端架构

两端均为**纯 SPA + Nginx + Tailwind**，共享 `packages/shared-types`（类型）与 `packages/shared-ui`（设计系统）。

## 8.1 技术栈

- Vue 3 `<script setup>` + TypeScript
- Vite（构建/开发）
- Pinia（状态管理）
- Vue Router（路由）
- Tailwind CSS（样式）
- axios（HTTP，拦截器注入 Bearer token）
- `@ai-insight/shared-types`（DTO / 枚举 / SPI 契约）
- `@ai-insight/shared-ui`（编辑风设计系统）

> 符合 vue-best-practices 规范：Composition API + `<script setup>` + TypeScript。

## 8.2 用户端（apps/user）— 编辑风，复刻原型

视觉基线：`v2-editorial.html`（The Insight Review · 你的 AI 周刊）。设计 token（`--paper/--ink/--vermillion/--mustard/--forest/--cobalt/--rose`）迁移到 `shared-ui`。

### 路由与页面

| 路由 | 页面 | 功能 |
|---|---|---|
| `/` | 本期报告 | 头版头条 + 统计卡 + 本周精选（领域筛选+时间窗）+ 供稿榜 + 档案 + 领域点评/趋势（深度报告新增） |
| `/archive` | 往期报告 | 按期浏览（不做全文检索） |
| `/reports/:id` | 报告详情 | 单期报告完整内容 |
| `/settings` | 订阅设置 | 勾选领域 + 填关键词 + 选择挂载的 schedule + 推送通道偏好 |
| `/feedback` | 我的反馈/收藏 | 反馈/收藏记录 |

### 区块对应原型
| 原型区块 | 数据来源 |
|---|---|
| 报头 / 顶部跑马灯 | Report.issueNo / periodEnd |
| 头版头条 | Report.headlineJson |
| 统计卡（By the Numbers） | Report.bodyJson 汇总 |
| 编辑荐语 | Article.trendComment（深度报告） |
| 本周精选（领域筛选+时间窗） | Report.bodyJson 条目 + Category 过滤 |
| 来自档案 | 往期 Report 列表 |
| 供稿榜 | Report.bodyJson 按 source 聚合 |

### 数据特性
- 所有数据来自后端已生成的 `reports`（打开即读，**非实时计算**）。
- 时间窗（当天/三日/一周/一月/半年/全部）与领域筛选在前端对当前 Report 的 bodyJson 做客户端过滤（与原型交互一致）。

## 8.3 管理端（apps/admin）— 深色控制台风

与用户端编辑风视觉区分，采用深色专业控制台风格。

### 路由与页面

| 路由 | 页面 | 功能 |
|---|---|---|
| `/dashboard` | 仪表盘 | 运行指标：采集/处理/推送状态、队列健康、最近错误 |
| `/sources` | 数据源 | CRUD：选 type → 填 config、启用/禁用、手动触发采集、查 collect_logs |
| `/categories` | 领域定义 | code/label/color/排序 |
| `/schedules` | 报告调度 | ReportSchedule：定义报告调度目标（日报/周报）+ 各自 cron + periodHours |
| `/cron` | 全局 cron | 采集/处理 cron 配置 |
| `/proxy` | HTTP 代理 | 出网代理配置（应用内自定义代理客户端） |
| `/reports` | 报告管理 | 报告列表（含 status）+ 手动重推 + 事后纠错 |
| `/users` | 用户管理 | 用户列表 + 改 role（USER↔ADMIN） |
| `/channels` | 通知通道 | 通道查看 + 密钥配置 + 连通性测试 |

## 8.4 认证与请求

两端共用认证逻辑：
- 路由加载时调用使用方登录接口取得 token（**登录代码使用方实现**，平台留接口/占位）。
- axios 请求拦截器注入 `Authorization: Bearer <token>`。
- 401 → 重定向登录；403（访问 admin 但非 ADMIN）→ 提示无权限。

管理端额外：路由守卫校验 `role === 'ADMIN'`，非 ADMIN 不可进入。

## 8.5 部署形态

- 两端各自 `pnpm build` 产出静态资源。
- 各自由 Nginx 托管静态资源 + 反代 `/api` 到后端 Fastify。
- docker-compose 中 `user` 与 `admin` 各一个 nginx 容器。

```nginx
server {
  listen 80;
  root /usr/share/nginx/html;
  location / { try_files $uri $uri/ /index.html; }   # SPA history fallback
  location /api/ { proxy_pass http://server:3000/; } # 反代后端
}
```
