# 15 · UI/UX 设计

本平台的视觉语言以项目根目录 `v2-editorial.html` 原型为基线。**用户端**直接复刻原型的「编辑风周刊」美学；**管理端**沿用同一套设计 token 与字体系统，但转向「深色专业控制台」风格，保持品牌一致性。

---

## 15.1 设计基线：原型提取

### 15.1.1 配色系统（CSS 变量 token）

> 全部迁移到 `packages/shared-ui`，作为两端共享的设计 token。

| Token | 色值 | 用途 |
|---|---|---|
| `--paper` | `#f4efe6` | 纸张主背景（暖米白） |
| `--paper-2` | `#ece5d6` | 纸张次背景（区块/卡片底） |
| `--ink` | `#1a1612` | 主文字 / 主边线（近黑暖墨） |
| `--ink-2` | `#4a423a` | 次要文字 |
| `--ink-3` | `#8a8073` | 辅助文字 / 标签 |
| `--rule` | `#1a1612` | 分隔线 |
| `--vermillion` | `#c8341a` | 朱红（主强调 / AI 领域 / 头条 / 印章） |
| `--mustard` | `#d4a017` | 芥末黄（数据高亮 / CLIMATE / BREAKING 标） |
| `--forest` | `#2d5a3d` | 森绿（BIO 领域 / 在线状态点） |
| `--cobalt` | `#1d3b6e` | 钴蓝（QUANT 领域） |
| `--rose` | `#a83a5c` | 玫红（SOC 领域） |

### 15.1.2 字体系统

| 字体族 | 字体 | 用途 |
|---|---|---|
| 衬线展示 | **Fraunces**（opsz 可变，300–900） | 大标题、头条、统计数字、引文、期号 |
| 正文 | **Inter Tight**（400–700） | 正文段落、UI 文字 |
| 等宽 | **JetBrains Mono**（300–500） | 数据、标签、时间戳、期号编号、元信息 |

字体加载：Google Fonts；`shared-ui` 统一引入 `@import`。

### 15.1.3 视觉语言要素

| 要素 | 实现 | 说明 |
|---|---|---|
| 纸张纹理 | `body::before` SVG fractalNoise 噪点（opacity 0.5） | 编辑风的「印刷质感」底纹 |
| 分隔线 | `border-b-[3px]`、`double-rule`（3px 双线）、`thick-rule`（4px 实线） | 报纸版面切分 |
| 印章效果 | `stamp`（2px 朱红边、rotate -6°、letter-spacing 0.1em、等宽字） | 头版标签、TOP STORY |
| 首字下沉 | `drop-cap`（Fraunces 900、4.2rem、朱红） | 头条摘要首字 |
| 荧光标记 | `marker`（芥末黄 60% 底高光） | 编辑荐语中的重点词 |
| 跑马灯 | `marquee-ink`（墨底纸字）+ `slide-track`（50s 无限滚动） | 报头顶部信息条 |
| hover 升起 | `hover-lift`（translateY -3px，cubic-bezier） | 卡片悬停反馈 |
| 入场动画 | `reveal`（opacity 0→1 + translateY 14→0，0.6s） | 内容渐显，按 index 错峰 |
| 表格数字 | `tabular`（font-variant-numeric: tabular-nums） | 统计数字等宽对齐 |
| 热度条 | 10 格像素条，按 heat/10 填充朱红 | 文章热度可视化 |

### 15.1.4 交互模式

- **时间窗选择条**：分段按钮组（当天/三日/一周/一月/半年/全部），active 态墨底纸字，border-2 包裹成一组。
- **领域筛选**：胶囊按钮，带领域色点（`w-2 h-2`），active 态墨底纸字。
- **空状态**：斜体衬线大字 + 等宽小字提示（如「— 本期暂无更多内容 —」）。

## 15.2 用户端 UI/UX（编辑风，直接复刻原型）

### 15.2.1 设计调性
**「The Insight Review · 你的 AI 周刊」** —— 把 AI 洞察包装成一份严肃优雅的纸质周刊。强调阅读仪式感、版面层次、印刷质感。完全沿用 15.1 的 token、字体、视觉要素。

### 15.2.2 全局布局规范

- **最大宽度**：`max-w-[1400px] mx-auto`，左右 `px-6 md:px-10`。
- **报头/报尾**：墨色（`--ink`）跑马灯 + 粗线分隔。
- **背景**：`--paper` 纸色 + 噪点纹理。

### 15.2.3 页面级设计

#### 页面 A：本期报告（`/`）— 核心页面，对应原型主体

完整复刻原型六大区块：

| 区块 | 设计要点 |
|---|---|
| **① 报头** | 墨色跑马灯（VOL/期号/日期/订户/BREAKING）+ 大字刊名「The Insight Review」（Fraunces black，clamp 2.8–5.6rem）+ 期号 № + 双线导航条（今日/档案/订阅/作者/关于）+ 在线状态点 |
| **② 时间窗选择条** | `--paper-2` 底，分段按钮组（当天/三日/一周/一月/半年/全部）+ 右侧统计（共 N 篇 / 第 X 期） |
| **③ 头版头条区**（grid 12 列） | 左 7 列：`stamp`「头版·TOP STORY」+ 大标题（Fraunces black，clamp 2.2–3.8rem）+ 首字下沉摘要 + 标签 + 继续阅读；右 5 列：**统计卡**（墨底纸字，2×2 数字网格，Fraunces 斜体大字）+ **编辑荐语**（朱红 ¶ + 荧光标记） |
| **④ 本周精选** | 章节标题（罗马序 II. + Fraunces）+ 领域筛选胶囊 + 三列网格卡片（顶部色块 + 来源 + 标题 + 摘要 + 10 格热度条 + 相对时间） |
| **⑤ 来自档案 + 供稿榜**（grid 3 列） | 左 2 列：档案列表（编号 + 标题 + 来源 + 日期，虚线分隔）；右 1 列：供稿榜（大序号 + 来源 + 篇数 + 横向占比条） |
| **⑥ 报尾** | 墨底纸字「— END OF DISPATCH —」+ 订户数 + 下一期寄出时间 |

#### 页面 B：往期报告（`/archive`）
- 报头复用；主体为**期号卡片网格**：每卡显示期号（Fraunces 斜体大字）、日期、头条标题、收录篇数、领域色点。
- 点击进入 `/reports/:id`（与本期报告同布局）。

#### 页面 C：报告详情（`/reports/:id`）
- 与本期报告**同布局**，只是数据为指定历史期。

#### 页面 D：订阅设置（`/settings`）
- 报头复用；主体为**编辑风表单卡片**：
  - 领域勾选：复用领域筛选胶囊（多选）。
  - 关键词：等宽字标签输入（chip 形式，回车添加）。
  - 调度目标选择：单选卡片（日报/周报，显示 cron 说明）。
  - 推送通道偏好：多选胶囊（CONSOLE/EMAIL/...，带通道色点）。
  - 保存按钮：墨底纸字 + 朱红下划线 hover。

#### 页面 E：我的反馈/收藏（`/feedback`）
- 两栏列表：**收藏**（COLLECT）+ **反馈**（USEFUL/USELESS），每条显示文章标题、领域色点、反馈类型标签、时间。

## 15.3 管理端 UI/UX（深色控制台，同 token 派生）

### 15.3.1 设计调性

**「印刷厂控制室」** —— 与用户端同源的设计语言（同字体、同强调色），但反相为**深色基底**，强调数据密度、状态清晰、操作高效。寓意：用户端是「印好的报纸」，管理端是「编排印刷的工厂控制台」。

### 15.3.2 深色 token 派生（复用 + 反相）

管理端在 `shared-ui` 基础上派生一组**反相 token**，颜色关系与用户端一致：

| 管理端 Token | 色值 | 关系 |
|---|---|---|
| `--bg` | `#1a1612`（= 用户端 `--ink`） | 深色主背景（暖墨黑） |
| `--bg-2` | `#241e18` | 卡片/区块底（略亮） |
| `--bg-3` | `#2e261e` | hover/选中底 |
| `--surface` | `#f4efe6`（= 用户端 `--paper`） | 主文字（纸色文字） |
| `--surface-2` | `#c8c0b3` | 次要文字 |
| `--surface-3` | `#8a8073`（= `--ink-3`） | 辅助文字/标签 |
| `--line` | `rgba(244,239,230,0.12)` | 分隔线（纸色低透明） |
| 强调色 | 直接复用 `--vermillion / --mustard / --forest / --cobalt / --rose` | 与用户端完全一致 |

> 设计意图：反相 token 让两端「同源不同面」，朱红/芥末/森绿等强调色在深底上更跳，状态语义统一（朱红=错误/头条、芥末=警告/高亮、森绿=成功/在线、钴蓝=信息）。

### 15.3.3 字体（完全复用）
- Fraunces：管理端用于**关键数字与标题**（仪表盘大数、页内大标题）。
- Inter Tight：正文与 UI。
- JetBrains Mono：**数据/状态/时间戳/JSON/code**（管理端大量用等宽展示配置与日志）。

### 15.3.4 全局布局

- **左侧固定侧边栏**（深色 `--bg-2`，纸色文字）：Logo + 导航分组（运行监控 / 内容配置 / 推送管理 / 系统）。
- **顶栏**：当前页标题（Fraunces）+ 用户头像/角色 + 退出。
- **主内容区**：`--bg` 底，卡片用 `--bg-2` + `--line` 边框。
- 响应式：窄屏侧边栏折叠为图标。

### 15.3.5 视觉要素（继承 + 调整）

| 要素 | 管理端调整 |
|---|---|
| 纸张纹理 | **去掉**（控制台要清晰，不要噪点） |
| 分隔线 | 改用 `--line`（纸色低透明 1px），保留双线/粗线用于强调区块 |
| 印章效果 | 保留 `stamp`，用于状态标签（如「TOP STORY」「已发送」「失败」） |
| hover 升起 | 保留 `hover-lift`，用于卡片 |
| 热度条 | 保留 10 格像素条，用于 Article 热度 |
| 状态点 | 森绿=运行中/在线、芥末=等待、朱红=失败、钴蓝=信息 |
| 等宽表格 | 大量使用 mono 字体展示数据表、配置、日志 |

### 15.3.6 页面级设计

#### 页面：仪表盘（`/dashboard`）
- 顶部：**关键指标卡网格**（4 列）：今日采集条数 / 待处理 / 本期报告数 / 推送成功率，数字用 Fraunces 斜体大字 + 状态色。
- 中部：**队列健康**（4 个队列的实时状态，状态点 + 积压数）。
- 下部：**最近错误列表**（mono 等宽，朱红 error，可跳转重试）。

#### 页面：数据源（`/sources`）
- 左：**数据源列表表**（code/name/type/启用/最近采集状态/操作），type 用色点。
- 右/抽屉：**编辑表单**（type 选择 + config JSON 编辑器，mono 字体）。
- 顶部：「手动触发采集」「新建」按钮（PaperButton 深色变体）。
- 下：该源 `collect_logs` 折叠表（状态点 + itemsFetched/itemsNew + 时间 + error）。

#### 页面：领域定义（`/categories`）
- 简单 CRUD 表 + 颜色选择器（预置 5 色 token）。

#### 页面：报告调度（`/schedules`）
- **调度目标卡片网格**：每卡显示名称（Fraunces）+ cron（mono，可编辑）+ periodHours + 启用开关 + 挂载的订阅数。
- 内联 cron 编辑 + 校验提示。

#### 页面：全局 cron（`/cron`）
- 两个 cron 输入（采集/处理）+ 下次触发时间预览（mono）。

#### 页面：HTTP 代理（`/proxy`）
- 表单：host/port/认证 + 「测试连通」按钮（结果显示状态点）。

#### 页面：报告管理（`/reports`）
- **报告表**：issueNo（mono）/ 用户 / schedule / status（状态点/印章）/ 生成时间 / 操作（查看/重推）。
- 详情抽屉：预览 bodyJson + 「手动重推」按钮。

#### 页面：事后纠错
- Article 列表 + 编辑：改 summary（textarea）/ heat（滑块或数字）/ critical（开关），保存。

#### 页面：用户管理（`/users`）
- 用户表：name/externalId(mono)/role（下拉 USER↔ADMIN）/最后活跃。

#### 页面：通知通道（`/channels`）
- **通道卡片网格**：每卡 channel 名 + 状态点 + 「配置密钥」「测试」按钮。
- 测试结果用 mono + 状态点反馈。

## 15.4 响应式与可访问性

### 15.4.1 响应式断点（两端共用）
| 断点 | 行为 |
|---|---|
| `< md`（移动） | 用户端网格降为单列；管理端侧边栏折叠 |
| `md–lg` | 用户端精选 2 列；管理端侧边栏展开 |
| `≥ lg` | 用户端精选 3 列、头版 12 列布局完整 |

### 15.4.2 可访问性
- **对比度**：用户端纸墨对比足够；管理端深底纸字对比需 ≥ 4.5:1（`--surface` on `--bg` 达标）。
- **焦点态**：所有交互元素有可见 focus ring（朱红 2px outline）。
- **语义化**：报头 `<header>`、导航 `<nav>`、主体 `<main>`、文章 `<article>`、报尾 `<footer>`。
- **键盘**：时间窗/领域筛选按钮可 Tab + Enter；表格行可键盘操作。
- **动效**：`reveal`/`slide` 尊重 `prefers-reduced-motion`（降级为即时显示）。
- **色盲**：状态不仅靠颜色，辅以图标/文字（状态点 + 文字标签）。
