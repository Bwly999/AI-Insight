## 3. 任务卡

### [ ] 任务 4.1 delivery.worker

> 验收：E2 / E3 / E4 / E5 / E6

**接口签名**

```ts
// apps/server/src/workers/delivery.worker.ts
export async function startDeliveryWorker(app: FastifyInstance): Promise<void>;
// Worker('delivery-queue', async (job) => deliverReport(app, job.data))
// job.data: { reportId: number }
```

**文件路径**
- 新建 `apps/server/src/workers/delivery.worker.ts`
- 新建 `apps/server/src/services/delivery.ts` — 核心
- 修改 `apps/server/src/main.ts`

**实现要点**

`deliverReport(app, { reportId })`：
1. 查 report + user + subscription（取 channels）
2. 对每个 channel in subscription.channels：
   - 幂等检查：`notification_logs.idempotency_key = reportId:channel` 已存在 SUCCESS → 跳过
   - 查 `app.notifiers.get(channel)`；不存在 → 记日志 status=FAILED + error='channel not registered'，继续下一个
   - 构造 `NotificationPayload`（subject/summary/reportUrl/reportDeepJson 从 report 取）
   - `const result = await notifier.send(payload)`（catch 失败 → 记 FAILED + error，抛出让 BullMQ 重试）
   - 记 notification_logs（status=SUCCESS/FAILED, idempotency_key, payload）
3. 全部通道处理完 → 更新 report.status=SENT + sent_at

**幂等键**：`${reportId}:${channel}`，notification_logs.idempotency_key 唯一索引（Phase 0 已有）

**验收点**
- E2 / E3 / E4 / E5 / E6
