## 3. 任务卡

### [ ] 任务 3.1 report.worker（裁剪组装）

> 验收：D1 / D2 / D3 / D4

**接口签名**

```ts
// apps/server/src/workers/report.worker.ts
export async function startReportWorker(app: FastifyInstance): Promise<void>;
// Worker('report-queue', async (job) => generateReports(app, job.data))
// job.data: { scheduleId: number }
```

**文件路径**
- 新建 `apps/server/src/workers/report.worker.ts`
- 新建 `apps/server/src/services/report-builder.ts` — 核心裁剪逻辑
- 修改 `apps/server/src/main.ts`

**实现要点**

`generateReports(app, { scheduleId })`：
1. 查 report_schedules 取 cron/periodHours；算时间窗 `[now - periodHours, now]`
2. 查 subscriptions（scheduleId, active=true）取所有目标用户
3. 查该时间窗内所有 articles（已处理的）
4. 对每个用户：
   - 裁剪：articles 命中 `subscription.categoryCodes ∪ keywords` 的保留
   - 排序：critical 优先，其次 heat 降序
   - 组装 headlineJson（最高 heat/critical 一条）+ bodyJson（featured 前 20 + archive 其余）
   - issueNo：`{scheduleCode}.{YYYYMMDD}-{seq}`（seq 同日递增）
   - insert reports（status=READY）+ report_items（articleId/sortOrder/section）

时间窗 articles 查询：用 `articles.processed_at BETWEEN periodStart AND periodEnd`
裁剪 SQL：用 JSON_CONTAINS(categoryCodes) 或 LIKE 匹配 keywords（tags/summary）

**验收点**
- D1 / D2 / D3 / D4
