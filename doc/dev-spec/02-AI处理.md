## 3. 任务卡

### [ ] 任务 2.1 processing.worker 五阶段

> 验收：C2 / C3 / C4

**接口签名**

```ts
// apps/server/src/workers/processing.worker.ts
export async function startProcessingWorker(app: FastifyInstance): Promise<void>;
// Worker('processing-queue', async (job) => processBatch(app, job.data))
// job.data: { since?: string }  // 处理某时间后的 raw_items；空则处理所有未处理的
```

**文件路径**
- 新建 `apps/server/src/workers/processing/` 目录
  - `dedupe.ts` — 阶段 a：语义去重
  - `classify.ts` — 阶段 b：分类打标
  - `summarize.ts` — 阶段 c：中文摘要
  - `score-heat.ts` — 阶段 d：热度评分
  - `comment.ts` — 阶段 e：综合点评（仅 critical 条目）
  - `index.ts` — 编排五阶段
- 新建 `apps/server/src/workers/processing.worker.ts` — Worker 入口
- 修改 `apps/server/src/main.ts`

**实现要点**

阶段 a（dedupe）：
- 取本批 raw_items，对每条算「标题相似度」（用 LLM 判重，prompt：「以下两条是否指同一事件？回答 yes/no」）
- 与库内最近 7 天的 raw_items 比对，相似则标记 duplicate，不进 articles
- 一次 LLM 调用判多条（batch，省 token）

阶段 b（classify）：
- `generateObject` + zod schema：`{ categoryCode: enum, tags: string[] }`
- categoryCode 值来自 categories 表的 code 列
- prompt：「对以下内容分类并打标（输出中文标签）：\n${rawText}」

阶段 c（summarize）：
- `generateText`：产出 100-200 字中文摘要
- **强制中文**：prompt 显式「无论原文什么语言，输出中文摘要」
- 失败回退：截 raw_text 前 200 字

阶段 d（score-heat）：
- `generateObject`：`{ heat: number(0-100) }`
- prompt 给评分维度：热度信号（源权威度 / 时效 / 影响范围 / 社区讨论度）

阶段 e（comment）：
- 仅对 heat>=70 或 critical 的条目做
- `generateText`：领域点评 + 趋势一句话

编排（index.ts）：
- 对每条 raw_item：a→b→c→d 串行，e 条件触发
- 全部结果 insert articles 表
- 异常：单条失败记 error 继续（不阻塞批），整批失败 worker 抛错让 BullMQ 重试

**验收点**
- C2（字段齐全）/ C3（中文）/ C4（语义去重）
