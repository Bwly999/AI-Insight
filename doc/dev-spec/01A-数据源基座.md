```ts
  mask(plain: string): string;      // 脱敏：前 4 + **** + 后 4
```

### [ ] 任务 1A.3 指纹去重工具

> 验收：B6

**接口签名**

```ts
// apps/server/src/collectors/fingerprint.ts
export type FingerprintStrategy = 'url' | 'title' | 'source_id';

export function normalizeUrl(url: string): string;
export function fingerprint(args: {
  url?: string;
  title?: string;
  sourceCode?: string;
  sourceId?: string;
}): { fingerprint: string; dedupeKey: string; strategy: FingerprintStrategy };
```

**文件路径**
- 新建 `apps/server/src/collectors/fingerprint.ts`

**实现要点**
- `normalizeUrl`：
  1. `new URL(url)`（失败则原样）
  2. 去 fragment (`hash`)
  3. 去跟踪参：`utm_*`, `from`, `ref`, `source`, `spm`, `fbclid`, `gclid`
  4. query 参数按 key 字典序排序
  5. 强制小写 host + 去 trailing slash
  6. 移除默认端口（:80/:443）
- `fingerprint` 策略选择：
  - 有 url → 'url' 策略：`sha256(normalizeUrl(url)).slice(0,16)`
  - 无 url 有 title → 'title'：`sha256(title 去标点空格).slice(0,16)`
  - 都无但有 sourceId → 'source_id'：`sha256(sourceCode + '::' + sourceId).slice(0,16)`
- `dedupeKey` = `${strategy}:${原值前40字符}`（用于排查「为何没去重」）

**验收点**
- 单元测试：
  - `normalizeUrl('https://a.com/x?b=2&a=1#top')` === `'https://a.com/x?a=1&b=2'`
  - `normalizeUrl('https://a.com/?utm_source=x')` === `'https://a.com/'`
  - `fingerprint({url:'https://a.com/x'})` 与 `fingerprint({url:'https://a.com/x?utm_source=y'})` 的 fingerprint 相同

> 验收：B3

**接口签名**

```ts
// apps/server/src/collectors/field-map.ts
export function getByPath(obj: unknown, path: string): unknown;
// path 如 'data.list' 或 'data.items[*]'（末段 [*] 通配返回数组）

export function extractItems(root: unknown, resultPath: string): unknown[];
export function mapFields(
  items: unknown[],
  fieldMap: { title: string; url: string; publishedAt?: string; summary?: string },
```

**文件路径**

**实现要点**

### [ ] 任务 1A.12 collection.worker

> 验收：B2/B4/B6/B8

**接口签名**

```ts
// apps/server/src/workers/collection.worker.ts
export async function startCollectionWorker(app: FastifyInstance): Promise<void>;
// 内部 new Worker('collection-queue', async (job) => processCollectJob(app, job.data));
```

**文件路径**
- 新建 `apps/server/src/workers/collection.worker.ts`
- 修改 `apps/server/src/main.ts` — 启动 worker（dev 模式同进程；生产可独立进程）

**实现要点**
- Worker 监听 `collection-queue`
- 每个 job data：`{ sourceId: number }`
- 流程：
  1. 查 sources 表取 source（不存在或 disabled → 跳过）
  2. 插 collect_logs（status=RUNNING, startedAt=now）
  3. `const collector = app.collectors.get(source.type)`；不存在抛错
  4. `const items = await collector.fetch({code, type, config})`（catch 失败 → 更新 collect_logs FAILED + error，重抛让 BullMQ 重试）
  5. 对每个 item 算 fingerprint，尝试 insert raw_items（unique 冲突 catch 跳过），累计 itemsNew
  6. 更新 collect_logs（status=SUCCESS, finishedAt=now, itemsFetched, itemsNew）
- BullMQ 配置：`attempts: 3, backoff: { type: 'exponential', delay: 5000 }`，deadletter queue（B8）
- 日志：见 `00-约定` §6.2

**验收点**
- B2 / B4 / B6 / B8
