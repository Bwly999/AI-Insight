三者都已落实的需求 2–7

以下不是"哪个原型有"，而是三个都做了——你选哪个都会拿到这些。

02 · 思考块完整
不再截断到 220 字
思考块完整展示，默认可折叠/展开。Dossier 用涂黑条、Margin 用页边批注、Loom 用卷轴装置——各自有签名性的折叠形态，而非简单收起。
03 · Markdown 渲染
对话流内全程 markdown
标题/加粗/列表/表格/代码/引用块/链接全部渲染，流式与历史统一（修复当前"流式纯文本、历史 markdown"的不一致）。
04 · 持续对话
左侧会话列表 + 跨轮保留
左侧"卷宗/草稿/线索"列表可切换历史会话；新对话不会清空旧的。原型展示了多轮追问的完整记录。
05 · 报告弹窗
不再跳转页面
点击报告卡片在本页弹出 modal（带 ESC 关闭、点遮罩关闭），不再 router.push 到独立路由，避免页面切换。
06 · 回看全要素
思考/工具/正文都保留
原型第一轮 AI 回复里就完整保留了思考、两个工具调用、markdown 正文——证明回看时不会只剩最后一段文字。（注：彻底修复需后端 executor 持久化 thinking/tool_result 消息，原型已为这些预留了渲染位。）
07 · 右侧仅数据源
工具调用移出右栏
右侧只放数据源条目（带来源类型 dot、标题、摘要、日期、域名），工具调用记录移到正文的工具卡里。Loom 更进一步用引用标记把正文结论和右侧证据一一对应。
