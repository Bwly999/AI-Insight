# 分类标签

技能使用五个标准的分类角色。此文件将这些角色映射到本仓库问题追踪器中实际使用的标签字符串。

| 技能中的标签名 | 本仓库的标签名 | 含义                          |
| -------------- | -------------- | ----------------------------- |
| `needs-triage` | `needs-triage` | 维护者需要评估此问题          |
| `needs-info`   | `needs-info`   | 等待报告人补充更多信息        |
| `ready-for-agent` | `ready-for-agent` | 已充分定义，AI 可直接接手 |
| `ready-for-human` | `ready-for-human` | 需要人工实现              |
| `wontfix`      | `wontfix`      | 不处理                        |

当技能提及某个角色时（例如"应用 AI 可接手的分类标签"），使用此表中对应的标签字符串。

如需修改，编辑右列以匹配实际使用的词汇。
